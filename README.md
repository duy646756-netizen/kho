# Kho Chỉ Chính Hãng

App quản lý kho, bán hàng và thu chi cho cửa hàng **Chỉ Chính Hãng VN**.

- Giao diện: `index.html` (chạy trên GitHub Pages)
- Máy chủ: `apps-script/Code.gs` (chạy trên Google Apps Script, dữ liệu trong Google Sheet)
- Cài đặt: xem `HUONG-DAN-CAI-DAT.md`

Không có mật khẩu hay địa chỉ máy chủ nào nằm trong mã nguồn —
địa chỉ Apps Script được nhập trong app và chỉ lưu trên máy người dùng.
